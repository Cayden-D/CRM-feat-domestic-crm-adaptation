# Project instructions

## Progress tracking

Whenever a feature, database migration, integration, test suite, or infrastructure item is added, completed, removed, or materially changed:

1. Update `DEVELOPMENT_PROGRESS.md` in the same change.
2. Check an item only after implementation and proportionate verification are complete.
3. Add a concise dated entry to the change log when the change affects project scope or a deliverable milestone.
4. Database changes must be added as a new numbered file under `database/migrations`; do not rewrite a migration that may already have been applied.
